## Hey, I'm HzzMonet 👋

I build and tinker with **Android tools, system integrations and automation**. Most of my work here revolves around **Kaorios** and exploring what happens beneath the Android UI.

- **Android customization** — framework patches, ROM integration and per-app controls.
- **Native development** — experimenting with Zygisk, JNI and Android internals.
- **Practical tooling** — scripts, build workflows and documentation that make the next iteration easier.
